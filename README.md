# 对拍

中文名：**对拍** · 前缀 `duet` · 端口 **7800**

## 骨架（新骨，不是闸对/缝包换皮）

**左轨装载 → 右轨装载 → 同键对齐落差 → 单边悬账 → 对拍结论**

| 对比 | 闸对 | 缝包（已弃） | **对本仓** |
| --- | --- | --- | --- |
| 拓扑 | 单流入→在途→成物 | 单流入→在途→成物 | **双轨独立装载→键对齐** |
| 在途态 | 开腿账 | 拼缝账 | **无开腿/拼缝；悬账是对齐后单边** |
| 产物 | 行程账 | 整件账 | **对齐差 + 对拍结论** |
| 旁路名 | 旁路匣 | 旁路匣 | **悬账单（命名与语义都不同）** |

皮：支付渠道回执 vs 核心记账。去皮：**双源键对齐管道**。禁止做成收银 CRUD、报表看板、工单系统。

## 已落实邻题

**双边幂等键（切流账册形态，全局唯一工程形态）**

- 事件编号跨左右轨全局唯一；`幂等账册` 钉已入编号，二次同号整票拒收，拒因入 `幂等拒收史` 可回读，现行流水不增行。
- 工程形态二选一只落「切流账册」一边，**不做**「双写两轨 + 只读归档」：无归档表，归档键恒空、归档条数恒 0；现行条数与归档条数在 `/api/幂等/水位` 分开。
- 查重、写流水、钉账册、记拒收在同一进程互斥锁 + 同一事务内同成败；账册主键对并发同号兜底，现行不得双行。
- 拒因（中文）：`幂等拒收-同轨二次同号` / `幂等拒收-异轨同号`（另一轨不写入）/ `幂等拒收-对齐键半边漂`。
- 只读接口：`GET /api/幂等/查?事件编号=&轨别=`（事件编号、轨别、拒因、归档键、形态标记、valid）；另有 `/api/幂等/账册`、`/api/幂等/拒收史`、`/api/幂等/水位`。
- 页面：左/右轨流水（装载回执中文命运 + 本轨拒收史 + 只读查询）、新增「幂等账册」页，对齐差/悬账/轨规/对拍台均可见幂等中文状态与水位。
